# 2026-07-06

## Document rich-powered console logging (framework 0.4.9)

- **Intent:** Document the framework's 0.4.9 change that re-renders `uvicore.log`'s console output
  with [rich](https://rich.readthedocs.io/) (see `framework/journal/2026-07-06.md`).
- **Changed:**
  - `epologue/changelog/0.4.md` — new `## 0.4.9` section (newest first) describing the rich console
    logging: full-width rule headers, glyph item bullets, notice/critical badges, `⚠`/`✖`
    prefixes; that `rich` is now a **base** dependency (not behind an extra); that the file handler
    and `dump()`/`dd()` are untouched; and the one behavior change (`WARNING`/`ERROR`/`CRITICAL` now
    go to STDERR, with `colors = False` as the plain STDOUT-only fallback).
  - `epologue/release-notes.md` — added a `0.4.9` bullet under `## 0.4`.
- **No feature page:** logging never had a dedicated `deeper/` page and the public `uvicore.log`
  interface is unchanged, so this was epologue-only.  A future `deeper/logging.md` could document the
  full `uvicore.log` API + the `UVICORE_LOG_THEME` re-skinning hook.
- **Validation:** `poetry run mkdocs build --strict` exits 0, no bad-link INFO lines.  Not committed
  (per user's commit policy).
