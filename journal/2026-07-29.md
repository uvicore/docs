# 2026-07-29

## New Logging page + epologue for framework 0.4.10 (dated log files & channels)

- **Intent:** Document the framework 0.4.10 logging work — date-stamped log filenames and named log
  channels — and fill what turned out to be a genuine hole: **logging had no docs page at all**.
  `deeper/` covered cache, redis, mail, templating, jobs, ioc, superdict and the http client, but
  logging appeared only in passing (a `bootstrap.md` table row, an `ioc.md` bullet, the 0.4.9
  changelog entry, and "use `uvicore.log.dump()` instead of `dump()`" notes in the middleware pages).
- **Changed — new `docs/deeper/logging.md`**, the canonical page for the whole subsystem, not just the
  new features. Sections: quick start; configuration (with *why* it is app-config-only — logging
  bootstraps before any package config merges, so that ordering is the point); levels including the
  custom `NOTICE` (25) and the STDOUT/STDERR split; layout helpers with a rendered `bash` sample;
  console output + the `colors: False` escape hatch; `dump()`; filters/excludes (explicitly calling
  out that matching is by **prefix, not exact name**, so an exclude of `Import` also kills `Importer`);
  `name()` scoping and that it is a *filtering* scope, not a destination; file logging; and channels.
- **File logging is documented as two modes side by side**, because which handler you get is decided
  purely by whether the configured filename contains strftime tokens. The dated mode is recommended
  with the concrete reasons (multi-process safety, the filename never lying, nothing renamed), and the
  legacy mode carries a `!!! danger` spelling out the real failure: with multiple processes on one
  file, the process that loses the rename race never rotates again and silently loses data. Also
  documented the two honest caveats of dated files — the cross-UID `EACCES` race, and `O_APPEND`
  atomicity holding only up to the ~8KB buffer.
- **Channels** documented with the five-section example from the original ask
  (`Auditor`/`Importer`/`Processor`/`RulesEngine`/`Transformer`), the inheritance rules, the
  "safe to hold across awaits" pattern (store it on `self` in a consumer class), the isolation
  guarantees, and the two gotchas: channels don't reach root handlers (`caplog`, Sentry) and channel
  names cannot contain a dot.
- **Epologue trio:** `epologue/changelog/0.4.md` gained a `## 0.4.10` section; `release-notes.md`
  gained a 0.4.10 bullet; `upgrade/from-0.3-to-0.4.md` gained a "New: Date-Stamped Log Files and Log
  Channels" section. Framed as opt-in with **one** thing actually worth acting on — anyone running
  multiple workers against a shared `LOG_FILE_PATH` is already losing log data today — plus the
  warning that `backup_count` does not apply to dated paths, so `retention` must be set or logs grow
  unbounded.
- **Wiring:** added `deeper/logging.md` to `mkdocs.yml` nav (after `deeper/mail.md`) and to the
  "What's Inside" list on `deeper/index.md`. `poetry run mkdocs build --strict` exits 0 with no
  `absolute link` / `unrecognized relative link` lines.
- **Files:** `docs/deeper/logging.md` (new), `docs/deeper/index.md`, `mkdocs.yml`,
  `docs/epologue/changelog/0.4.md`, `docs/epologue/release-notes.md`,
  `docs/epologue/upgrade/from-0.3-to-0.4.md`.
